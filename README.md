A professional WordPress theme for medical billing and healthcare services.

== Description ==

Prime Doc Billing is a modern, professional WordPress theme designed specifically for medical billing companies and healthcare service providers. The theme features a clean, responsive design built with Tailwind CSS and optimized for performance.

= Features =

* Responsive design that works on all devices
* Built with Tailwind CSS for modern styling
* Optimized for performance with lazy loading images
* SEO-friendly with proper schema markup
* Custom page templates for services
* Blog and search functionality
* Translation ready
* Custom widgets and sidebars
* Font Awesome icons support
* AOS (Animate On Scroll) library integration
* Slick slider for testimonials and content carousels

= Services Supported =

* Medical Billing
* Medical Coding
* Credentialing
* Prior Authorization
* Verification of Benefits
* Denial Management
* Account Receivables
* Practice Management
* Revenue Cycle Management
* Medical Scribing
* Virtual Assistant Services
* Workers Compensation Billing
* Website Development

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.

= Manual Installation =

1. Upload the theme folder to the `/wp-content/themes/` directory
2. Activate the theme through the 'Appearance > Themes' menu in WordPress

== Frequently Asked Questions ==

= Does this theme support custom menus? =

Yes, this theme supports WordPress custom menus in one location (Primary Menu).

= Does this theme support widgets? =

Yes, the theme includes a sidebar widget area.

= Is this theme translation ready? =

Yes, the theme is translation ready and includes a .pot file in the languages directory.

= Does this theme support the Block Editor? =

Yes, the theme supports the WordPress Block Editor (Gutenberg) with align-wide and responsive embeds support.
